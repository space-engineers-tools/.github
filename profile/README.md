## Our Mission

This Org is a place for everything that doesn't belong in the [Space Engineers Workshop](https://steamcommunity.com/app/244850/workshop) like libraries or modding tools.

## How to Contribute

You are welcome to create pull requests for any of the repos at any time.

Do you have an idea for a tool/library that would benefit the Space Engineers community?

**Create a post in the [Discussion](https://github.com/orgs/space-engineers-tools/discussions).**

<details>
<summary>How to become a maintainer?</summary>

If you are interested in becoming a maintainer of a repository, please reach out to an [Organization Member](https://github.com/orgs/space-engineers-tools/people) or use the [Discussion](https://github.com/orgs/space-engineers-tools/discussions) section.
</details>
